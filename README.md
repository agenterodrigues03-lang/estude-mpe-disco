## 🎯 Como Usar Este Repositório

### **Organização por Disciplina**
Cada pasta principal contém subdivisões lógicas da matéria, facilitando localização rápida.

### **Sistema de Estudos**
- **01-xx** = Resumos e anotações teóricas
- **02-xx** = Conceitos intermediários
- **03-xx** = Jurisprudência e súmulas
- **04-xx** = Questões comentadas (maior foco)

### **Boas Práticas**
✅ Use arquivos `.md` (Markdown) para anotações  
✅ Crie pastas para cada tópico importante  
✅ Documente jurisprudência com links  
✅ Registre erros no arquivo `03-resumo-erros`  
✅ Atualize a matriz de habilidades regularmente

## 💡 Dicas Importantes

1. **Faça resumos sua própria letra mental** - Não copie literalmente
2. **Jurisprudência é ouro** - Priorize decisões STF/STJ
3. **Questões antes de resumo** - Veja o que é cobrado antes
4. **Conexão entre tópicos** - Entenda como os temas se ligam
5. **Revisão sistemática** - Spaced repetition (SRS)
